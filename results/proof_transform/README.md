# Proof-Transformation Graph

Generated by:

```bash
python3 analysis/proof_transform_graph.py all \
  --min-support 12 --min-theorems 5 --min-premises 2 --max-premises 6 --top 50
```

The graph is trace-derived from LeanDojo.  It expands tactic applications into
operation nodes and premise-level primitive-operation nodes:

- `simp`, `simpa`, `simp_all`, `dsimp`, and `field_simp` become `simp_search`
  operations with selected simp rules.
- `rw`, `rwa`, `erw`, `nth_rw`, and `rw_mod_cast` become specified rewrite
  operations with rewrite-rule direction when recoverable from the annotated
  tactic text.
- `exact`, `refine`, and `apply` become term-elaboration operations with the
  referenced declarations exposed.

Large generated JSONL graph files are ignored by git:

- `primitive_ops.jsonl`
- `graph_nodes.jsonl`
- `graph_edges.jsonl`
- `motif_candidates.jsonl`

Committed compact outputs:

- `summary.json`: graph-size and operation-count summary.
- `motif_summary.json`: candidate-search settings and top candidates.
- `motif_candidates_top.json`: top candidate motifs with examples.

Important limitation: LeanDojo does not record the exact matched subterm or the
internal sequence of all simplifier rewrites.  This implementation exposes the
premises LeanDojo annotated and the before/after goal hashes/excerpts.  A later
Lean-side tracer would replace those approximations with exact matched
subterms, generated side goals, and elaborated proof terms.
