# Report Figure Generation

Figures in this directory are generated by:

```bash
python3 analysis/audit_report_numbers.py
MPLCONFIGDIR=results/_matplotlib XDG_CACHE_HOME=results/_cache \
  python3 analysis/make_report_figures.py
```

`analysis/audit_report_numbers.py` reads compact JSON/JSONL result artifacts
and writes `results/audit/report_numbers.json`.  `analysis/make_report_figures.py`
then uses that audit file to produce paired PDF/SVG figures.  The PDF files are
used by `results/report.tex`; the SVG files are used by `results/report.md`.

The dependency-degree tail figure streams
`results/paths/dependency_edges.jsonl` and computes total degree from unique
incoming plus outgoing premise edges.  The proof-tree depth spread figure reads
the LeanDojo Benchmark 4 `train`/`val`/`test` traces under
`Old/data/leandojo/leandojo_benchmark_4/random/` and recomputes depth and width
from tactic-state branching.

`figure_manifest.json` records the numeric values used in each generated figure.
